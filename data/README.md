# Dataset

`dataset.tsv` is the text-based dark pattern dataset from:

> Yuki Yada, Jiaying Feng, Tsuneo Matsumoto, Nao Fukushima, Fuyuko Kido, Hayato Yamana.
> **Dark patterns in e-commerce: a dataset and its baseline evaluations.**
> 2022 IEEE International Conference on Big Data. [arXiv:2211.06543](https://arxiv.org/abs/2211.06543)

Source: https://github.com/yamanalab/ec-darkpattern (Apache License 2.0). The file is included here unchanged.

The dark pattern texts originally come from Mathur et al., *Dark Patterns at Scale: Findings from a Crawl of 11K Shopping Websites* (CSCW 2019).
